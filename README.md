## How to Compile and Run

```bash
gcc 01_Problem1.c -o 01_Problem1
./01_Problem1
```

For programs using math functions (Problem 22), link the math library:

```bash
gcc 22_Problem22.c -o 22_Problem22 -lm
```

- Variables, Input/Output
- Arithmetic, Relational, Conditional Operators
- Increment/Decrement Operators
- Control Flow (if-else, switch-case)
- Loops (for, while)
- Series and Sequences
- Functions (iterative and recursive)
- Pass by Value vs Pass by Reference
- Math Library Functions
- Arrays (1D and 2D)
- Matrix Operations
- String Handling
